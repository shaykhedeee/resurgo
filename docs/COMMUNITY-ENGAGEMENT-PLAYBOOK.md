## SECTION 4: CONVERSION OPTIMIZATION

### Landing Page A/B Testing (Week 1-2)

**Test 1: Hero Headline**
- Control: "Drop your goal. Get a real plan in 90 seconds."
- Variant A: "Five apps, zero execution. One system fixes that."
- Variant B: "The execution OS for builders who are tired of planning."
- Split: 50/50 traffic, run 2 weeks

**Test 2: CTA Button Text**
- Control: `START_FREE`
- Variant A: `BUILD_MY_PLAN`
- Variant B: `GET_MY_AI_COACH`
- Track: Click-through rate

**Test 3: Pricing Table**
- Control: 3-column (Free, Pro Monthly, Lifetime)
- Variant A: Pro Monthly highlighted / shadowed
- Variant A: Lifetime highlighted / shadowed
- Track: Conversion rate

**Tools:**
- Google Optimize (built into GA4)
- Or: Vercel Edge Config + URL params
