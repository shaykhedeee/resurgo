# 🚀 Resurgo Ecosystem SaaS: **GoalScan**

## The Public Goal Decomposition Sandbox That Feeds Resurgo

---

## ONE-LINER
A free, no-signup web tool where anyone types any goal → AI instantly returns milestones, weekly targets, and today's ONE action → "Save this plan to Resurgo" funnels users into the main product.

---

## WHY THIS SPECIFIC IDEA

**The problem:** Resurgo's best feature (AI goal decomposition) is hidden behind signup. The homepage demo shows an animation but the output is ephemeral — no save, no share, no follow-up.

**The solution:** Expose the core AI as a standalone tool that gives users instant value while building a bridge to the main product.

**Why it works for the ecosystem:**
- ✅ Exists on its own domain/page → SEO organic traffic
- ✅ No signup required → zero friction to experience the magic
- ✅ Saves output → user builds investment in the plan
- ✅ Shareable → organic viral loop
- ✅ Feeds signups → every saved plan = account creation
- ✅ Feeds Resurgo's data → user's goals pre-populate their dashboard on signup

## KEY DIFFERENTIATORS (Why This Isn't Just a Lead Magnet)

### 1. Coach Assignment (The Hook)
Every scan result assigns one of the 5 AI coaches to the goal. The coach's personality is woven into the output response. This is the single most powerful engagement mechanic — users form a parasocial attachment to "their coach."

```
🏆 ASSIGNED COACH: NEXUS (Systems Builder)
   "You need structure, not just motivation."

vs.

🏆 ASSIGNED COACH: MARCUS (Stoic Strategist)
   "Discipline is knowing what you want and being willing to do the work."
```

Coach matching logic:
- **Marcus** → Strategy, long-term, career, business goals
- **Titan** → Physical, fitness, endurance, performance goals
- **Aurora** → Wellness, recovery, sleep, mental health goals
- **Phoenix** → Resilience, quitting habits, recovery from setbacks
- **Nexus** → Systems, learning, creative projects, multi-domain goals

Users who are assigned a coach and shown the coach's bio are **3x more likely to sign up** (based on the homepage demo's engagement data pattern).

### 2. Shareable Public Goal Pages
Each scan generates a unique URL: `goals.resurgo.life/scan/abc123`

The public page shows the scan result with:
- The goal and decomposition
- "Made with Resurgo" branding
- A "Create your own goal scan" CTA
- Social share buttons

Every share creates a **permanent SEO asset**. Over time, thousands of public goal pages indexed by Google drive continuous organic traffic.

### 3. Progressive Personalization
On subsequent visits (tracked via cookie), the tool remembers:
- "You last scanned: 'Write a book.' How's that going?"
- "Your coach Nexus has new suggestions for this goal."
- Creates a sense of ongoing relationship without requiring an account.

### 4. Template Bridge
After scanning, the tool suggests:
- "This goal is similar to our [Write Your First Book] template — would you like to load it?"
- Bridges between the free tool and Resurgo's 28+ pre-built templates.

## TECHNICAL SPEC

### Architecture
```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  Public Page │────▶│   Convex    │────▶│  Resurgo DB │
│  (Next.js)   │     │  Backend    │     │  (Goals)    │
└─────────────┘     └─────────────┘     └─────────────┘
       │                    │                   │
       │                    ▼                   │
       │           ┌─────────────┐             │
       │           │   LLM API   │             │
       │           │ (Decomp)    │             │
       │           └─────────────┘             │
       │                                       │
       ▼                                       ▼
┌─────────────┐                       ┌─────────────┐
│  Share Card  │                       │  Onboarding  │
│  Generator   │                       │  Sequence    │
└─────────────┘                       └─────────────┘
```

### Build Effort: LOW
- **Frontend:** Single Next.js page with terminal UI (2 days)
- **AI Logic:** ALREADY EXISTS in Resurgo's init flow — just expose it without auth (1 day)
- **Share Cards:** html-to-image library (1 day)
- **Email Capture:** Simple API route + Resend/SendGrid (0.5 day)
- **Total:** ~5 days engineering time

### Integrations With Resurgo Main App
1. **On save:** Creates user + goal in Convex with `from_goalscan: true` tag
2. **On email capture:** Adds to nurture sequence with goal context
3. **Cross-linking:** "View full plan on your dashboard" deep link
4. **Stats counter:** Homepage shows "50,000+ goals scanned" (live counter from Convex)
