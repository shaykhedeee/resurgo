## TESTIMONIAL FORMAT

```
[OUTCOME HEADLINE - 5-7 words, specific metric/result]
"[Quote - 1-2 sentences, specific, no hype]"
— [First name, role/ICP, optional metric badge]
```

### Example:
```
Shipped 2 features in planning time
"I stopped using 5 apps for goals, habits, and sleep. Resurgo runs all three. The weekly AI review alone saves 2 hours every Sunday."

```

## RULES FOR TESTIMONIALS

1. **Never invent testimonials**
2. **Never edit to change meaning**
3. **Always ask permission before using names/roles**
4. **Use real user data only**
5. **Remove any identifying info if requested**
