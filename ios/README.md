# iOS Project Structure — Resurgo

This directory contains the native iOS project generated by Capacitor. **Do not edit files directly** unless you understand they may be overwritten on `npx cap sync ios`.

## Generated Structure

```
ios/
├── App/                      # Main Xcode project source
│   └── App/
│       ├── AppDelegate.swift          # App lifecycle, notification setup
│       ├── SceneDelegate.swift        # Multi-window scene management
│       ├── Info.plist                 # Bundle ID, permissions, URL schemes
│       ├── App.entitlements           # Code signing capabilities (push, domains)
│       ├── Assets.xcassets/           # App icons, launch images
│       │   ├── AppIcon.appiconset/    # All required icon sizes (generated)
│       │   └── LaunchScreen.launchimage/  # Legacy launch images (fallback)
│       └── LaunchScreen.storyboard   # Modern launch screen (Xcode 12+)
├── App.xcworkspace/           # CocoaPods workspace (includes Pods/)
├── App.xcodeproj/             # Xcode project file
│   └── project.pbxproj        # Actual project configuration
└── Podfile                    # CocoaPods dependencies ( Capacitor plugins)
```

## Important Files to Edit (Persisted)

Most native configuration should be done **outside** this folder to survive `npx cap sync`:

| What to configure | Where to edit |
|-------------------|---------------|
| App ID, version, build number | `capacitor.config.ts` → `appId`, then bump version in `android/app/build.gradle` (Android) and Xcode (iOS) manually |
| URL schemes,Associated Domains,Permissions | `capacitor.config.ts` (plugins section) + Xcode capabilities UI |
| Push notification certificates | Apple Developer portal → download → Xcode signing |
| Icons & splash screens | `public/icons/` and `android/app/src/main/res/` (icons), `capacitor.config.ts` → `plugins.SplashScreen` |
| Native plugins | Add via `npm install @capacitor/...` then `npx cap sync` |

## Files That Survive `npx cap sync`

- **`Info.plist`** — Capacitor merges server URL, permissions from config into this file. Custom entries added via `config.plist` in `capacitor.config.ts` survive.
- **`App.entitlements`** — Entitlements are preserved; Capacitor adds required capabilities.
- **`Assets.xcassets/`** — Icon sets and launch images are preserved.
- **`AppDelegate.swift` / `SceneDelegate.swift`** — If you add custom native code, it may be overwritten. Use plugins or Capacitor's `registerPlugin` approach instead.
- **CocoaPods (`Pods/`)** — `pod install` is re-run on sync, but `Podfile.lock` is preserved.

## Workflow

### Development (macOS only)
```bash
# Sync web assets to iOS project
npm run ios:sync

# Open Xcode
npm run ios:open

# In Xcode: Select a simulator/device → Run (⌘R)
```

### Signing (One-Time Setup)
1. Open Xcode → select **App** target → **Signing & Capabilities**
2. Choose your **Team** (Apple Developer account)
3. Enable **Automatically manage signing** (recommended)
4. Xcode creates certificates & provisioning profiles

**OR** manual signing (advanced):
- Create App ID in Apple Developer Portal
- Generate Distribution Certificate
- Create provisioning profile (App Store / Ad Hoc)
- Configure `ExportOptions.plist` for `xcodebuild -exportArchive`

See `docs/IOS-DEPLOYMENT.md` for detailed signing instructions.

### Build for Distribution
```bash
# Build App Store IPA
npm run ios:build

# Output: public/downloads/resurgo-latest.ipa
```

Alternatively, use Xcode:
- Product → Archive
- Organizer appears → Distribute App → App Store Connect / Ad Hoc

### Post-Build
```bash
# The IPA is ready to upload
# Use Transporter (Mac App Store) or Xcode Organizer:
open -a Transporter public/downloads/resurgo-latest.ipa
```

## Cleaning

To rebuild from scratch:
```bash
# Remove derived data (Xcode cache)
rm -rf ~/Library/Developer/Xcode/DerivedData/*

# Remove Pods and reinstall
cd ios
pod deintegrate
pod install
cd ..

# Full resync
npx cap sync ios
```

## Common Issues

### "No signing certificate 'Apple Distribution' found"
**Fix:** Xcode → Preferences → Accounts → Add Apple ID → Fetch certificates. Or enable automatic signing.

### "Command PhaseScriptExecution failed"
**Fix:** Usually CocoaPods missing or Firebase plist missing. Run `pod install` and ensure `GoogleService-Info.plist` exists in `ios/App/App/`.

### "The app is not authorized to use push notifications"
**Fix:** Enable Push Notifications capability in Xcode → Signing & Capabilities. Upload APNs key to Firebase.

### "pod install` fails with `[!] Invalid `Podfile`"
**Fix:** Ensure you're in the `ios/` directory and CocoaPods is up to date: `sudo gem install cocoapods`.

### "xcodebuild: error: The operation couldn't be completed."
**Fix:** Clean build folder in Xcode (⇧⌘K) or `xcodebuild clean`.
